## 게시 순서 (@teamplus.kr)

1. 프로필 정비 먼저 — 이름 칸을 `팀플러스+ | 아이스하키 클럽 관리앱` 으로(인스타 내부 검색에 걸림), 소개글 첫 줄에 한 문장 정의, 링크 1개.
2. 새 게시물 → `card1.png` ~ `card5.png` **순서대로** 5장 업로드 → 자르기에서 **원본 비율(4:5)** 선택.
3. `caption.txt` 내용을 그대로 붙여넣고 공유.
4. 게시 직후 **첫 댓글**에 `comment.txt` 한 줄을 붙여넣기. (개행 없이 한 줄 — 인스타 댓글창은 Enter 가 전송이라 여러 줄은 잘립니다.)
5. 게시 후 30분은 댓글에 즉답. 게시물 수정은 하지 않습니다(초기 평가 리셋).
6. 시간대는 학부모 골든타임인 **밤 9~11시** 권장.

## 사실 검증 메모 (초안에서 걸러낸 것)

작성 과정에서 아래 표현은 **코드 확인 결과 사실이 아니어서 삭제**했습니다. 나중에 다시 쓰지 마세요.

- ❌ "일정이 바뀌면 알림이 먼저 옵니다" — 수업 회차 취소·변경 시 알림 발송 호출부가 없음(`class_cancelled` 템플릿은 정의만 존재). 실제 발송이 검증된 것은 **새 수업 등록 · 수강료 변경 · 결제 완료 · 출석 확인** 알림.
- ❌ "알림톡 → 푸시 → 문자 3단 발송" — SMS 는 알림톡 재시도가 **전부 실패했을 때만** 폴백이고 설정으로 끌 수 있음. 푸시는 별도 채널.
- ❌ "캘린더에서 아이별 색으로 구분" — 캘린더 색은 자녀가 아니라 **수업 유형**(정규/오픈/대회) 기준. 자녀는 색이 아니라 선택 필터로 걸러 봄. → "아이를 고르면 그 아이 일정만"으로 교정.
- ❌ `content.ts` 의 CASES 4건(안양 ACE 420명 등)·TRUST_LOGOS 12개 클럽 — **실제 고객이 아닌 플레이스홀더**. 홍보 인용 절대 금지.
- ❌ 가격·요금제·무료체험 — `PRICING.price` 는 전부 "준비 중"이고 정기결제·구독 기능 자체가 미구현.
- ❌ 사용자 수·다운로드·처리 건수 등 실적 수치 — 실측치 없음.

## @sellerease.kr — 확정 후 재작성 완료 (2026-08-03)

사용자 확인 결과 **@sellerease.kr = KCS BackOffice SAS 2.0**((주)케이씨에스의 사내 백오피스 + 셀러 포털)로 확정됐습니다. 아래 "보류 이유"는 그 이전 기록이며, `sellerease/` 의 캡션·카드는 **KCS 저장소(`~/developerApp/react/new-kcs-core-sys-front`) 코드 검증을 거쳐 전량 다시 쓴 것**입니다.

재작성 시 코드로 걸러낸 오귀속 (다시 쓰지 마세요):

- ❌ "6개 마켓 주문을 한 목록에서" — 셀러 계정은 `ProtectedRoute` 에서 `/seller/*` 밖으로 나가면 리다이렉트된다. 셀러가 실제로 보는 마켓 화면은 쿠팡·스마트스토어·11번가 3개뿐.
- ❌ "MAWB·콘솔리데이션을 셀러에게 열었다" — 항공화물은 KCS·커넥트랩 관리자 전용 경로.
- ❌ "통관부호 검증" 을 셀러 기능으로 — 셀러에게 열린 건 **통관오류 현황**뿐. (로그인 없는 `/cv/:token` 공개 검증은 수취인용 별개 화면)
- ❌ "부가세·세금계산서·환율·크레딧" — 전부 KCS 백오피스 경로. 셀러 정산 화면은 하나.
- ❌ "지금 들어와서 첫 화면을 보세요" — 가입(signup/register) 라우트가 0건이라 실행 불가능한 CTA. → **계정 발급은 DM 문의**가 유일하게 성립하는 CTA.
- ❌ 효과·수치 주장("시간이 줄어듭니다") — 측정 근거 0건.

**스토어 링크 댓글은 이 계정에 달 수 없습니다.** 웹 전용이라 앱이 존재하지 않습니다 → `comment.txt` 는 그 사실과 DM 안내로 대체했습니다.

## (이전 기록) @sellerease.kr 이 보류였던 이유

`sellerease/caption.txt` 상단 참조. 요약하면 **이 계정이 어떤 제품의 계정인지 확정되지 않았습니다.**

- "셀러이즈 / SellerEase" 문자열은 로컬 전체 스윕에서 **0건**.
- `sellerease.kr` 은 살아 있으나 페이지 브랜딩이 **"KCS BackOffice SAS 2.0"**(author: LoginFlow), 서빙 실체는 `~/developerApp/react/new-kcs-core-sys-front` 빌드.
- 캡션에 담긴 기능(발주서 수집·합배송·통관고유부호 검증·건별 수익계산·이슈 추적)은 **`~/developerApp/react/CONNECTLAB`**(구 Profit Guard / 물류통합관리시스템, 운영 도메인 `system.glslogi.com`) 코드에서 검증한 것.
- 두 제품이 같은 것인지 다른 것인지 확인 전에는 게시 금지. 다른 제품이면 타사 기능을 자기 것처럼 홍보하는 셈이 됩니다.

**확인해야 할 것 한 줄**: `@sellerease.kr` 은 CONNECTLAB(=Profit Guard)의 새 브랜드인가, KCS BackOffice 의 브랜드인가, 아니면 제3의 서비스인가.

또한 이 제품은 **웹 전용이라 모바일 앱이 없습니다.** "안드로이드·아이폰 스토어 경로" 댓글은 이 계정에 달 수 없고, 접속 URL 안내로 대체해야 합니다.
